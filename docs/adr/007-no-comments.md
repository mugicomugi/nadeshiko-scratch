# ADR-007: 公開ギャラリーにコメント欄を実装しない

- **状態**: **承認済**（2026-09-16、ユーザー承認）
- **日付**: 2026-09-16

## 状況

ユーザー決定は「**Scratch のように作品を公開し、他の子の作品を見る／リミックスする**」であり、コメントは明示的には含まれていない。これを「コメントは含意されていない」と解釈してよいかをユーザーに確認し、**承認を得た**。

## 決定

**最終形でもコメント欄（自由記述）を実装しない。**

代替: **定型スタンプ20種**（1ユーザー1作品あたり最大3種）＋ いいね ＋ みた数 ＋ リミックス数。
**スタンプの送信者は作者に表示せず集計だけを出す**（個人を特定した称賛／無視が発生しない）。

## 根拠

1. 東京都北区が 2023-07-21 に本家 Scratch を端末から遮断した公式回答は「第三者との共有機能や**コメント機能**があるため」であり、**コメントは名指しで挙がっている**
2. コメントは1作品あたり無限に増えるため、**モデレーション工数が作品数ではなくコメント数に比例する**。作品数ベースの工数試算（最悪ケースで40分/日）が成立しなくなる
3. 情報流通プラットフォーム対処法が求める削除申出への7日以内対応を、コメントまで含めて小規模チームで守ることは現実的でない
4. **Scratch ですら 3.0 で「教師が生徒の作品コメントを削除する機能」を失っており**、本家でも運用が成立していない

## 却下した代替案

| 案 | 却下理由 |
|---|---|
| 事前承認制のコメント | 工数がコメント数に比例する問題が解決しない |
| 作者のみが削除できるコメント | 子どもに加害への対処を負わせることになる |

## 影響

- 「Scratch の代替」としては機能が1つ欠ける。中学生の受容性に影響しうる（S-29 で検証）
- 自由入力面が「作品のなまえ（定型語選択）」と「せりふ」の2つに収束し、モデレーション面積が構造的に小さくなる

## 例外として残している検討

**org 内限定・教員承認制のコメント**（＝公開ギャラリーではなく学校テナント内の機能で、モデレーション責任が教員にある）は Phase 6 の検討対象として残す。S-29 の結果次第ではこちらを先に開ける選択肢もある。

## 再評価トリガー

- S-29 で中学生の「これなら使う」が過半に届かず、かつ理由がコメント不在である → org 内限定コメントを中学のみ先行して検討
